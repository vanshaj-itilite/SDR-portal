# SDR Portal

A unified portal for the SDR team.

---

## Roadmap

### v1 — Foundation & Tracking
Initial tracking and linking all workings into the system. Minimal UI — focus is on wiring up data sources, core workflows, and getting everything connected end-to-end.

### v2 — Full UI & Team Views
Full UI enhancements including different views tailored for different teams (SDRs, managers, ops, etc.). Improved UX, role-based dashboards, and richer data presentation.

### v3 — Scale, Reliability & Integrations
Scalability, data reliability, and interlinking with alerts, notifications, tracking systems, feedback loops, and more. Production-grade infrastructure and cross-system integrations.
